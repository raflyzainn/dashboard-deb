# Poin 6.13 — Panduan pengisian

Panduan akun kampus dan bantuan PKS diselaraskan dengan alur pengajuan baru: nomor PKS kampus diisi kampus, nomor PF diisi admin, dan permintaan nomor PF dibuat otomatis saat nomor kampus disimpan. Tidak ada klaim nomor diterbitkan otomatis. Kedua nomor dan PDF PKS terbaru wajib lengkap sebelum pengajuan. PDF disiapkan PF; pemeriksaan berurutan PF → Legal mendahului tanda tangan final.

Panduan menjelaskan urutan SK ≤ PKS < permohonan ≤ invoice < kuitansi, tanggal kuasa setelah PKS, periode per kampus, serta tanggal yang tidak otomatis bergeser. Pindaian mengikuti format yang diterima; surat kuasa memakai PDF/PNG/JPG, sementara pindaian surat pencairan juga menerima WebP. PF memeriksa pindaian dan menyimpan paket lampiran; kampus tidak menyusun paket sendiri. Tombol paket gabungan belum tersedia pada UI kampus.

Hanya teks pada halaman panduan dan komponen bantuan yang diubah. Urutan/key checklist tersimpan, API, aturan transaksi, data pengajuan, database, dan generator dokumen tidak diubah.

## QA browser lokal

- Playwright melalui tool Node REPL dengan browser Chrome terpisah; frontend 5176 dan PocketBase lokal 8097. Browser standar terkunci sehingga tidak digunakan.
- Login Institut Teknologi Bandung: panduan baru tampil dan tetap ada setelah reload; instruksi tombol permintaan manual tidak ada, urutan PF → Legal terlihat.
- Tautan Lihat pencairan membuka `/campus/pencairan`.
- Desktop dan layar 390 × 844 diperiksa; lebar konten mobile 380 px sama dengan lebar dokumen, tanpa overflow horizontal. Screenshot lokal `.local/guide-613-desktop.png` dan `.local/guide-613-mobile.png`.
- Akun Universitas Sriwijaya: bantuan PKS dapat dibuka dan menampilkan instruksi terbaru; lebar mobile 380 px tanpa overflow. Tidak mengubah checklist atau data pengajuan.
- Tidak ada pageerror pada rangkaian pemeriksaan panduan utama. Percobaan awal menunggu kartu terlalu cepat mengalami timeout; halaman dibuka ulang dan bantuan diperiksa setelah konten selesai dimuat.
- Tidak mengulang transaksi pengajuan, persetujuan Legal, tanda tangan, pembayaran, maupun QA production. Test suite, check, dan lint terminal tidak dijalankan.
